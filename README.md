# ArrowMaster

A puzzle game inspired by "Arrows – Puzzle Escape" with enhanced UI, monetization, and player experience.

## Features
- 1000+ handmade puzzle levels
- Minimalist design with modern and classic themes
- Offline support
- Improved touch accuracy
- Fair monetization model
- Skip/pass button
- Difficulty selection

## Target Specs
- Resolution: 1080x1920 (HD)
- FPS: 60
- App Size: 50-100 MB
- Platforms: Android, iOS

## Tech Stack
- Engine: Unity 2022.3.0 LTS
- Language: C#
- Version Control: Git/GitHub

## Project Structure

├── Assets/
│   ├── Scenes/
│   ├── Scripts/
│   ├── Prefabs/
│   └── StreamingAssets/Levels/
├── ProjectSettings/
└── README.md


## Getting Started
1. Clone the repository
2. Open with Unity 2022.3.0 or later
3. Load the main scene
4. Play!
